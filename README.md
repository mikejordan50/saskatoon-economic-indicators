# Saskatoon Regional Economic Indicators Dashboard

**Live dashboard: <https://mikejordan50.github.io/saskatoon-economic-indicators/>**

72 economic indicators for the Saskatoon Census Metropolitan Area — labour,
housing, construction, and prices — built from Statistics Canada Web Data
Service tables and updated after StatCan releases.

Maintained by Mike Jordan. This repository hosts the rendered site; the
source is maintained privately. Inspired by Philip Smith's
[Canadian Macroeconomic Indicators Dashboard](https://philipsmith.ca/macroindicators/macroindicators.html).
